## 🔴 必须完成（不做不能发版）

### 1. 版本号与发布管理（任务 14）

**为什么必须**：没有版本号无法跟踪发布，也无法接入 Sparkle 更新。

- [x] 确定 semver 版本号方案
- [x] Info.plist `CFBundleShortVersionString` 与 Git tag 对齐
- [x] 构建脚本自动注入版本号和 commit hash
- [ ] 首次打 `1.0.0` tag

**预估工作量**：0.5 天

---

### 2. 搜索和过滤（任务 19）

**为什么必须**：hosts 条目超过几十条后没有搜索几乎不可用，是最高频用户操作。

- [x] 编辑器侧边栏顶部添加搜索框
- [x] 实时过滤分组和节点名称
- [x] 过滤结果保持树状结构展示
- [x] 支持搜索 hosts 域名（在节点内容中匹配）
- [x] 空结果时展示空状态提示

**预估工作量**：1～2 天

---

### 3. 结构化日志（任务 22 最小集）

**为什么必须**：一旦写入失败或 XPC 断开，没有日志无法排查问题。

- [x] 使用 `OSLog` 覆盖关键路径：XPC 连接/断开、hosts 写入成功/失败、备份操作、配置加载
- [x] 设置页增加「导出诊断日志」按钮
- [x] 日志级别：error / warning / info / debug

**预估工作量**：1 天

> [!NOTE]
> 崩溃报告（Sentry 等）可推迟到 1.1，初期靠 Apple Crash Reports 即可。

---

### 4. CI/CD 发布流水线（任务 17）

**为什么必须**：手动跑 `build-release.sh` 容易遗漏签名/公证步骤，自动化才可持续。

- [ ] GitHub Actions workflow：tag push 触发
- [ ] 安装证书和 provisioning profile（通过 secrets）
- [ ] `xcodebuild archive` + `xcodebuild -exportArchive`
- [ ] `xcrun notarytool` 公证
- [ ] 生成 DMG
- [ ] 生成 Sparkle `appcast.xml`
- [ ] 自动创建 GitHub Release，上传 DMG + appcast.xml

**预估工作量**：1～2 天

---

### 5. Sparkle 自动更新（任务 16）

**为什么必须**：独立分发没有 App Store 推送，手动更新对用户不友好。

- [ ] 引入 Sparkle 框架（Swift Package Manager）
- [ ] 配置 `SUFeedURL` 指向 GitHub Releases appcast XML
- [ ] 首次发版时生成 `appcast.xml`
- [ ] 设置更新检查间隔（默认 24 小时）

**依赖**：任务 17 的 CI 产出 appcast.xml

**预估工作量**：1 天

---

### 6. DMG 安装体验（任务 26 剩余）

**为什么必须**：用户拿到 DMG 需要清晰的安装引导。

- [ ] 准备 DMG 背景图（拖拽安装指引）
- [ ] 准备 GitHub 页面作为临时官网 / landing page

**预估工作量**：0.5 天

---

## 🟡 可延后到 1.x 迭代

| 任务 | 说明 | 对应编号 | 优先级 |
|------|------|---------|--------|
| 全局快捷键 | 提升效率但不影响基本使用 | 任务 18 | P2 |
| 配置导入导出 | 换机迁移场景，低频 | 任务 20 | P3 |
| 通知中心集成 | 写入结果通知，菜单栏状态已够用 | 任务 21 | P3 |
| 大文件性能验证 | 常规 hosts 不超过几百行 | 任务 23 | P2 |
| VoiceOver 可访问性 | 合规需要但不影响主流使用 | 任务 24 | P2 |
| 隐私政策 | 不联网不收集数据，风险低 | 任务 25 | P3 |
| i18n 诊断文本收敛 | 底层日志残留英文，用户基本看不到 | 任务 15 | P3 |
| iCloud 同步 | 多设备场景 | 后置功能 | P3 |

## 推荐推进顺序

```
任务 14 版本号管理     ─ 最先做，0.5 天 ─►
任务 19 搜索过滤       ─ 用户体验关键 ─►
任务 22 OSLog 日志     ─ 关键路径覆盖 ─►
任务 17 CI/CD          ─ 自动化发版 ─►
任务 16 Sparkle        ─ 依赖 CI appcast ─►
任务 26 DMG 安装体验   ─ 打磨安装流程 ─►
                       打 1.0.0 tag 🎉
```

**总工作量估算**：5～7 天
