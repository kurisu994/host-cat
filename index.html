核心功能

开发者需要的一切

HostCat 专为频繁切换 hosts 的开发者设计，让复杂的 hosts 管理变得简单直观。

🎯

菜单栏一键切换

常驻菜单栏，分组和节点勾选即时切换。500ms 智能延迟写入，避免频繁操作抖动。

✨

语法高亮编辑器

基于 TextKit 2 的 hosts 专属编辑器。IP 蓝色、域名绿色、注释灰色，实时语法错误标记。

🔍

合成预览 + 冲突检测

实时预览最终合成的 hosts 文件。自动检测重复条目和同域名不同 IP 冲突，阻止错误写入。

💾

自动备份恢复

每次写入前自动备份当前 hosts，保留最近 3 份快照。事务式恢复，一键回滚到任意备份。

⌨️

全局快捷键唤起

自定义任意全局快捷键，一键弹出菜单栏窗口。无需鼠标移到状态栏，编码、调试、演示场景无缝切换。

🧹

DNS 缓存自动刷新

写入成功后自动执行 DNS 缓存刷新，无需手动在终端敲命令。改完即生效，零等待。

安全架构

5 道关卡，守护你的 /etc/hosts

HostCat 通过 SMAppService 注册的特权 Helper 进程安全地写入系统 hosts 文件。 主应用永远不以 root 身份运行。

🛡️ XPC 双向签名验证 📝 原子写入保证

🔒 隐私优先

不联网、不收集、不上传。所有配置仅存储在本地 ~/Library/Application Support。 首次启动即向你完整披露 Helper、网络、第三方组件边界。
